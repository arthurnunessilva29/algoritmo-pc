# 💻 Algoritmos e Pensamento Computacional

Este repositório reúne exercícios, atividades práticas e projetos desenvolvidos durante a disciplina de **Algoritmos e Pensamento Computacional**, ministrada pelo **Prof. Marco Antonio Sanches Anastacio**, na **Universidade Cruzeiro do Sul**, durante o segundo semestre de 2026.

Durante as aulas, são estudados conceitos de lógica de programação e desenvolvimento de algoritmos utilizando a linguagem C. O objetivo é aprender a analisar problemas, planejar soluções e desenvolver programas aplicando os conhecimentos adquiridos.

---

## 🎯 Objetivo da disciplina

A disciplina tem como finalidade desenvolver o raciocínio lógico e ensinar como transformar problemas em soluções computacionais. Para isso, são trabalhados conceitos de algoritmos, planejamento e implementação de programas.

**Principais conteúdos estudados:**

- 🧠 Lógica de programação e pseudocódigo.
- Variáveis, constantes e tipos de dados.
- Comandos de entrada e saída.
- Operadores aritméticos, relacionais e lógicos.
- Estruturas condicionais (`if`, `else` e `switch...case`).
- Estruturas de repetição (`for`, `while` e `do...while`).
- Vetores, matrizes e strings.
- Manipulação de arquivos.
- Funções, modularização e estruturas (`struct`).

## 📚 Evolução do aprendizado

Os conteúdos da disciplina seguem uma sequência de aprendizado, começando pelos fundamentos da programação e avançando para conceitos mais elaborados.

1. **Fundamentos:** introdução aos algoritmos, pseudocódigo e primeiros programas em C.
2. **Operadores e cálculos:** utilização de expressões matemáticas e operadores lógicos.
3. **Decisões:** desenvolvimento de programas com condições e diferentes possibilidades de execução.
4. **Repetições:** utilização de laços para automatizar tarefas.
5. **Organização de dados:** aplicação de vetores, matrizes e strings.
6. **Manipulação de arquivos:** armazenamento e recuperação de informações.
7. **Modularização:** utilização de funções e estruturas para organizar o código.

Os projetos realizados durante o semestre ajudam a aplicar esses conhecimentos na resolução de problemas práticos.

## ⚙️ Como compilar e executar

Os programas foram desenvolvidos em linguagem C e podem ser compilados utilizando o GCC.

**1. Compilação:**

```bash
gcc programa.c -o programa
```

**2. Execução no Linux ou WSL:**

```bash
./programa
```

Para programas que utilizam funções da biblioteca `math.h`, como `sqrt()`, `pow()` e `ceil()`, pode ser necessário adicionar `-lm`:

```bash
gcc programa.c -o programa -lm
```
